# Zen v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Zen v0.2 around a small first-party CLI that closes the dev/prod gap by orchestrating Fiber, Air, Vite, and the HTTP renderer from one command.

**Architecture:** Zen remains glue. Developers still use Fiber, Vite, Preact, Tailwind, and Air directly, but the Zen CLI coordinates the boring process slop: dev renderer, production renderer, Go app, frontend builds, manifest validation, and environment defaults. `ZEN_ENV=prod` switches the same orchestration path from dev behavior to production behavior.

**Tech Stack:** Go, Fiber, Vite, Preact, Tailwind, Air, Node, pnpm, `os/exec`, `net/http`, Go `testing`, Node `node:test`.

---

This follows the uploaded planning format: file map first, bite-sized tasks, failing tests before implementation, exact paths, concrete snippets, commands, expected results, and a self-review. 

Air is the right fit here because it is explicitly a live-reloading command-line utility for Go applications; Vite already provides the frontend dev/build half, including the `vite` dev command and build pipeline. ([GitHub][1])

## v0.2 Scope

v0.2 should add:

```text
zen dev
  starts the dev renderer
  starts the Go app through Air
  prefixes logs
  shuts everything down together

ZEN_ENV=prod zen dev
  builds frontend if needed
  starts production renderer
  starts Go app in production mode

zen build
  builds frontend client bundle
  builds frontend SSR bundle
  builds Go app binary

zen check
  verifies required tools and paths

zen init
  writes a minimal zen.config.json and .air.toml
```

v0.2 should not add:

```text
Zen router
Zen loaders
Zen actions
Zen forms
generated frontend types
islands
streaming
RPC
deployment adapters
```

Yes, we are making a CLI. No, we are not making a lifestyle brand.

package zencli

import "strings"

type Mode string

const (
	ModeDev  Mode = "dev"
	ModeProd Mode = "prod"
)

func modeFromEnv(env []string) Mode {
	value := ""

	for _, item := range env {
		if strings.HasPrefix(item, "ZEN_ENV=") {
			value = strings.TrimPrefix(item, "ZEN_ENV=")
			break
		}
	}

	switch strings.ToLower(strings.TrimSpace(value)) {
	case "prod", "production":
		return ModeProd
	default:
		return ModeDev
	}
}

package zencli

import (
	"encoding/json"
	"os"
	"path/filepath"
)

type Config struct {
	AppCommand       string `json:"appCommand"`
	AirCommand       string `json:"airCommand"`
	FrontendDir      string `json:"frontendDir"`
	DevRendererPort  int    `json:"devRendererPort"`
	ProdRendererPort int    `json:"prodRendererPort"`
	BinaryPath       string `json:"binaryPath"`
}

func defaultConfig() Config {
	return Config{
		AppCommand:       "go run .",
		AirCommand:       "air",
		FrontendDir:      "frontend",
		DevRendererPort:  5173,
		ProdRendererPort: 4174,
		BinaryPath:       "./bin/app",
	}
}

func loadConfig(root string) (Config, error) {
	cfg := defaultConfig()
	path := filepath.Join(root, "zen.config.json")

	raw, err := os.ReadFile(path)
	if err != nil {
		if os.IsNotExist(err) {
			return cfg, nil
		}
		return Config{}, err
	}

	if err := json.Unmarshal(raw, &cfg); err != nil {
		return Config{}, err
	}

	if cfg.AppCommand == "" {
		cfg.AppCommand = "go run ."
	}
	if cfg.AirCommand == "" {
		cfg.AirCommand = "air"
	}
	if cfg.FrontendDir == "" {
		cfg.FrontendDir = "frontend"
	}
	if cfg.DevRendererPort == 0 {
		cfg.DevRendererPort = 5173
	}
	if cfg.ProdRendererPort == 0 {
		cfg.ProdRendererPort = 4174
	}
	if cfg.BinaryPath == "" {
		cfg.BinaryPath = "./bin/app"
	}

	return cfg, nil
}
```

import "strconv"

type ProcessCommand struct {

	Env  []string

	return ProcessCommand{
		Name: "sh",
		Args: []string{"-c", command},
	}
}

func airCommand(cfg Config) ProcessCommand {
	cmd := shellCommand(cfg.AirCommand)
	cmd.Env = []string{"ZEN_ENV=dev"}
	return cmd

func goProdCommand(cfg Config) ProcessCommand {
	cmd := shellCommand(cfg.BinaryPath)
	cmd.Env = []string{"ZEN_ENV=prod"}
	return cmd

func devRendererCommand(cfg Config) ProcessCommand {
	return ProcessCommand{
		Name: "node",
		Args: []string{
			"js/dev-renderer.mjs",

			"--host",

package zencli

import (
	"bufio"
	"fmt"
	"io"
)

func prefixLines(input io.Reader, output io.Writer, prefix string) error {
	scanner := bufio.NewScanner(input)

	for scanner.Scan() {
		if _, err := fmt.Fprintf(output, "[%s] %s\n", prefix, scanner.Text()); err != nil {
			return err
		}
	}

	return scanner.Err()
}

import (
	"context"
	"io"
	"os"
	"os/exec"
)

type ManagedProcess struct {
	Name    string
	Command ProcessCommand
	Stdout  io.Writer
	Stderr  io.Writer
}

func (p ManagedProcess) Run(ctx context.Context) error {
	cmd := exec.CommandContext(ctx, p.Command.Name, p.Command.Args...)
	cmd.Dir = p.Command.Dir
	cmd.Env = append(os.Environ(), p.Command.Env...)

	stdout, err := cmd.StdoutPipe()
	if err != nil {
		return err
	}

	stderr, err := cmd.StderrPipe()
	if err != nil {
		return err
	}

	if err := cmd.Start(); err != nil {
		return err
	}

	done := make(chan error, 2)

	go func() {
		done <- prefixLines(stdout, p.Stdout, p.Name)
	}()

	go func() {
		done <- prefixLines(stderr, p.Stderr, p.Name)
	}()

	waitErr := cmd.Wait()

	for i := 0; i < 2; i++ {
		if err := <-done; err != nil {
			return err
		}
	}

	return waitErr
}
```

package zencli

import (
	"context"
	"fmt"
	"net/http"
	"time"
)

func waitForHealth(ctx context.Context, baseURL string, interval time.Duration) error {
	client := &http.Client{
		Timeout: interval,
	}

	url := baseURL + "/__zen/health"
	ticker := time.NewTicker(interval)
	defer ticker.Stop()

	for {
		req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
		if err != nil {
			return err
		}

		res, err := client.Do(req)
		if err == nil {
			_ = res.Body.Close()
			if res.StatusCode >= 200 && res.StatusCode < 300 {
				return nil
			}
		}

		select {
		case <-ctx.Done():
			return fmt.Errorf("renderer health check failed: %w", ctx.Err())
		case <-ticker.C:
		}
	}
}

package zencli

import (
	"context"
	"fmt"
	"io"
	"time"
)

func Run(args []string, env []string, stdout io.Writer, stderr io.Writer) error {
	if len(args) == 0 {
		_, _ = fmt.Fprintln(stdout, "zen dev | build | check | init")
		return nil
	}

	root := "."
	cfg, err := loadConfig(root)
	if err != nil {
		return err
	}

	switch args[0] {
	case "dev":
		mode := modeFromEnv(env)
		plan := planForMode(mode, cfg)

		ctx, cancel := context.WithCancel(context.Background())
		defer cancel()

		errs := make(chan error, len(plan))

		for _, item := range plan {
			proc := ManagedProcess{
				Name:    item.Name,
				Command: item.Command,
				Stdout:  stdout,
				Stderr:  stderr,
			}

			go func() {
				errs <- proc.Run(ctx)
			}()
		}

		port := cfg.DevRendererPort
		if mode == ModeProd {
			port = cfg.ProdRendererPort
		}

		healthURL := fmt.Sprintf("http://127.0.0.1:%d", port)
		if err := waitForHealth(ctx, healthURL, 100*time.Millisecond); err != nil {
			cancel()
			return err
		}

		err := <-errs
		cancel()
		return err

	case "build":
		for _, step := range buildPlan(cfg) {
			proc := ManagedProcess{
				Name:    step.Name,
				Command: step,
				Stdout:  stdout,
				Stderr:  stderr,
			}

			if err := proc.Run(context.Background()); err != nil {
				return err
			}
		}

		return nil
	case "check":
		return runCheck(stdout)
	case "init":
		return runInit(root)
	default:
		return fmt.Errorf("unknown command %q", args[0])
	}
}

# Zen v0.2

Zen v0.2 adds a small CLI for process orchestration.

It still does not replace Fiber, Vite, Preact, Tailwind, or Air. It only starts them in the correct order with the correct environment.

## Commands

zen init
zen check

ZEN_ENV=prod zen dev

go install github.com/air-verse/air@latest

```bash
zen dev
```

```text
renderer: node js/dev-renderer.mjs
app:      air -c .air.toml
```

The renderer runs Vite middleware and handles:

```text
GET  /__zen/health
POST /__zen/render
```

The app runs through Air and restarts when Go files change.

```bash
ZEN_ENV=prod zen dev
```

This runs:

```text
pnpm --dir frontend build
go build -o ./bin/app .
node js/prod-renderer.mjs
ZEN_ENV=prod ./bin/app
```

## Philosophy

Zen does not invent a route system.
Zen does not invent a form system.
Zen does not hide Fiber.
Zen does not hide Vite.
Zen does not hide Air.

It just keeps you from having to remember which terminal gets which cursed command.
