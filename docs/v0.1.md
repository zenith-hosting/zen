# Zen v0.1

Zen is tiny glue for Fiber, Vite, Preact, and Tailwind.

It does not replace Fiber routing.
It does not replace Vite configuration.
It does not replace Preact components.
It does not define a form system, data layer, client router, auth layer, or database layer.

It only connects a Fiber handler to a Vite-powered Preact SSR page.

## Mental Model

```text
Fiber request
  -> normal Fiber handler
  -> renderer.Render(c, "PageName", props)
  -> Node SSR worker renders Preact
  -> Zen assembles HTML document
  -> browser hydrates Preact page
```

## Install

```bash
go get github.com/zenith/zen/zen
pnpm add preact preact-render-to-string vite @preact/preset-vite @tailwindcss/vite tailwindcss
```

## Go Usage

```go
app := fiber.New()

renderer, err := zen.New(zen.Config{
	Dev: true,
	ViteURL: "http://localhost:5173",
	SSRCommand: []string{
		"node",
		"./frontend/ssr-worker-dev.mjs",
	},
	DefaultTitle: "My App",
})
if err != nil {
	log.Fatal(err)
}
defer renderer.Close()

app.Get("/", func(c fiber.Ctx) error {
	return renderer.Render(c, "Home", map[string]any{
		"title": "Hello",
	}, zen.WithTitle("Home"))
})
```

## Production Usage

```go
renderer, err := zen.New(zen.Config{
	Dev: false,
	ClientDist: "./frontend/dist/client",
	Manifest: "./frontend/dist/client/.vite/manifest.json",
	SSRCommand: []string{
		"node",
		"../../js/ssr-worker.mjs",
		"--entry",
		"./frontend/dist/server/entry-server.js",
	},
})
if err != nil {
	log.Fatal(err)
}
defer renderer.Close()

app.Get("/assets/*", renderer.Static())
```

## Frontend Contract

Create a server entry that exports `render(request)`.

```tsx
import { h } from "preact";
import renderToString from "preact-render-to-string";
import { pages } from "./pages";

export async function render(request) {
	const Page = pages[request.page];

	if (!Page) {
		throw new Error(`Unknown page: ${request.page}`);
	}

	return {
		html: renderToString(<Page {...request.props} />),
		head: ""
	};
}
```

Create a client entry that reads `#__ZEN_DATA__` and hydrates `#app`.

```tsx
import { h, hydrate } from "preact";
import { pages } from "./pages";
import "./app.css";

const data = JSON.parse(document.getElementById("__ZEN_DATA__").textContent);
const Page = pages[data.page];

hydrate(<Page {...data.props} />, document.getElementById("app"));
```

## What v0.1 Does Not Include

* No Zen router
* No Zen loaders
* No Zen actions
* No Zen forms
* No client router
* No islands
* No streaming
* No RPC generator
* No generated TypeScript types
* No auth layer
* No database layer

Use Fiber, Vite, Preact, and Tailwind directly.
Zen is just the bridge.
